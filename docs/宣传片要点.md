# 「虾米看AI」宣传片要点

> 给做片子的人的一页纸。数字取自 2026-08-13 的库（`node scripts/validate.mjs` 会打印同一批）。
> **看到「⚠️」的地方是最容易被讲偏的点。**

---

## 一句话

**这是一张能核验的 AI 能力地图**：每一格「这个模型能不能做这件事」，
背后都挂着厂商官方原文、来源链接和核验日期。

不是榜单，不是评测，不是导航站。

---

## ⚠️ 最容易被讲偏的三件事

### 1. 主角不是「✅」，是「⬜」

站上 593 个核心格子里，**⬜ 占 36%**（212 格）。很多人第一反应是「数据不全，别提」——
**恰恰相反，⬜ 是这个产品最值钱的东西**。

三色的含义是严格分开的：

| | 含义 | 门槛 |
|---|---|---|
| ✅ | 厂商官方说了它能 | **必须带官方原文引用 + 来源链接 + 核验日期**（340 格，无一例外） |
| ❌ | 厂商官方明确说了它不能 | 同样要原文。41 格 |
| ⬜ | **我们查了，公开渠道没说** | 每一格写清是「查过没找到」还是「还没查」 |

**「官方没说」和「不支持」是两件完全不同的事** —— 全网几乎没有第二个地方替你分开这两件事。
别的榜单遇到查不到就留空、或者干脆猜一个。

> 片子里可以这么说：**「这张表最诚实的部分，是它承认自己不知道什么。」**

### 2. 不打分、不排名、不推荐

- 效果只**转述**：第三方盲测榜怎么排、厂商自己怎么说，都标明「是谁说的」，我们不下判断
- 价格只**指路**：告诉你去哪个官方页看，不转述数字（转述必然过期）
- 工具箱每一条都必须写**负面结论**（校验规则 R49 拦着：没有 caveat 不许进库）

### 3. 它是活的，而且会自己发现自己错了

**97 条校验规则**卡在提交与构建之前，红了就没有产物。其中最有代表性的几条：

- **R9**：模型升版之后，旧版本的结论**不许沿用** —— 要么重新核，要么退回 ⬜。
  沿用旧证据必须显式标 `recheck`，并且一直算作待办
- **R68**：新开一个方向，四个公共页（可用性 / 变更 / 资源 / 教程）必须同步有内容，否则报错
- **R73**：没填中文别名的模型会被点名 —— 因为「中文关键词搜不到它」

## 拍得出画面的真实故事（比口号有力）

这些都发生过，日志与提交里都有据：

1. **别名表的由来。** 用 Kling 官方 171 条更新日志重核 11 个格子，
   **错了 4 个** —— 因为我们拿自己的词去搜厂商的文档。
   从此每项能力都带「各家怎么叫」的别名表。
2. **待办本身是错的。** 「补 SkyReels V4 的数据」躺在待办里，一查：**V4 根本不存在**。
3. **「GitHub 上没有」不等于「不存在」。** 判定「Hunyuan3D 3.0 查无此物」，
   后来在腾讯的官方 Replicate 账号上看到 3.1 —— 闭源那半边本来就不在 GitHub 上。
   两次纠错都留在原地，没有删掉。
4. **交叉源照出自己的漏。** 加了魔搭这条中文源之后，它报「万相 VACE 只有魔搭有」；
   一查 Hugging Face 明明有 —— 是**我们自己的折叠逻辑把整代吃掉了**
   （同一天发的小尺寸档当了代表，热度不够，整代被滤）。
   **交叉源的第一份价值不是发现新模型，是照出自己的漏。**
5. **有论文不等于有模型。** 混元 3D 的 Buffalo 1.0 技术报告发了，仓库里没有代码没有权重 ——
   当前版本照旧记 2.1。
6. **默认值踩在要停的那一支上。** Tripo 官方公告 API V2 将于 2026-11-01 停，
   而**不传参数时默认调的正是要停的 v2.5** —— 这种事只有逐条读文档才看得见。
7. **一天之内在两家身上踩同一个坑。** 「multi-view **generation**」（内部渲多视图）
   不等于「multi-**image** input」（接受多张输入图）—— 混元和 Seed3D 各差点记错一格。

## 谁会用它，用来干什么

不是「了解 AI 前沿」，是**要做出东西的人**在做具体决定时来查：

- 「我要做首尾帧的转场，现在有哪几个模型真支持、去哪个平台用？」
- 「这个能力是模型原生的，还是平台另开的一个接口？」（站上分得清）
- 「这家说开源，是标准开源协议还是自定义社区许可？」（一律标出来）
- 「我上次看是三个月前，这中间变了什么？」（变更页 + RSS）

---

## 不要说的话

- ❌ 「最全的 AI 模型库」 —— 我们**故意不求全**：每卷 Core ≤10 条产品线，
  其余进扩展层，凑数会把地图撑烂
- ❌ 「AI 评测 / 排行榜」 —— 我们不打分
- ❌ 「实时更新」 —— 是**按来源刷新周期人工复核**，站上每一格都写着核验日期
- ❌ 把 ⬜ 说成「待完善」 —— 它是结论的一种，不是进度条
